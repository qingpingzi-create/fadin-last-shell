# 最后一发：达舒科夫卡五小时

纯静态中文互动叙事网页。直接打开 `index.html` 即可离线游玩；不依赖框架、服务端或第三方资源。

## 发布到 GitHub Pages

1. 在 GitHub 新建一个公开仓库，例如 `fadin-last-shell`。
2. 上传本目录的全部文件：`index.html`、`styles.css`、`game.js`、`README.md`、`LICENSE`。
3. 在仓库的 **Settings > Pages** 中，将部署源设为 `Deploy from a branch`，选择 `main` 分支和 `/(root)`。
4. GitHub 生成的 `https://用户名.github.io/fadin-last-shell/` 即为分享链接。
